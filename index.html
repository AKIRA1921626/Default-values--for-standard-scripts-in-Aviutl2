■パラメータタイプ別文字色
normal (黒) / check (赤) / select (青) / path (黄) / color (橙) / value (紫)
パラメータタイプ別文字色詳細
normal (黒)
トラックバーで操作可能な数値。最小値と最大値を記載。

check (赤)
チェックボックスで、(1 or 0) or (true or false) を選択可能。

select (青)
リスト選択項目で選択可能な数値。選択肢を記載。

path (黄)
各種パスや参照先を指定でき、4つの項目から選べる。
画像ファイルから選択([AnyPath])
動画ファイルから選択([AnyPath])
シーン(Scene[N])
仮想バッファ(*tempbuffer)

color (橙)
色設定項目となり、「カラーコード（文字列）」 or 「16進数リテラル」で指定。

value (紫)
変数項目となり、キーボードでー数値などを自身で入力。
各種obj.effect()のコードは初期値を再現するため、
初期値で未指定の項目についてはあえて引数を一切与えずにスキップしています。 閃光
カテゴリ: 光効果
強さ = 100.0
min:0.0 / max:100.0
X = 0.0
min:-2000.0 / max:2000.0
Y = 0.0
min:-2000.0 / max:2000.0
合成モード = 前方に合成
options:[前方に合成,後方に合成,光成分のみ]
光色 =
type: color
サイズ固定 = 0
type: check
obj.effect("閃光","強さ",100.0,"X",0.0,"Y",0.0,"合成モード","前方に合成","サイズ固定",0)
ここでは初期値の光色が未指定のため、そこの引数指定を行っていない。
これでもエフェクトは機能します。

引数を指定した場合:
obj.effect("閃光","強さ",100.0,"X",0.0,"Y",0.0,"合成モード","前方に合成","光色","ffffff","サイズ固定",0)
